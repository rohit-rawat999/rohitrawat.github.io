# Rohit Rawat — Portfolio

Responsive GitHub Pages portfolio for Rohit Rawat, System Administrator | IT Infrastructure | Cloud & Security.

## Deploy

Repository name: `rohit-rawat999.github.io`

GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**

## Files

- `index.html` — portfolio page
- `assets/style.css` — responsive styling and animations
- `assets/script.js` — navigation, scroll reveal, project filters and progress bar
- `assets/Rohit-Rawat-Resume.pdf` — resume used by the Resume buttons
- `assets/favicon.svg` — site favicon

## Notes

- Static site; no build step or backend required.
- External Google Fonts are used for typography. The site still works if fonts are unavailable.
- Update links/contact details directly in `index.html` when needed.
