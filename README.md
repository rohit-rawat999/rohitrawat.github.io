# Rohit Rawat — Portfolio

Premium recruiter-focused static portfolio for Rohit Rawat.

Editable personal information, experience, skills, projects, learning and links are in `public/js/data.js`.

The site uses vanilla HTML/CSS/JavaScript, responsive glass UI, project/skill filtering, project detail modals, command palette, active section navigation, scroll progress, back-to-top, reduced-motion support, and refresh-scroll protection.

CV actions remain disabled until the real CV file is attached.
